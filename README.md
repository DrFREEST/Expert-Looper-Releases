# Expert Looper 다운로드

루틴을 만들고 재사용하는 Windows 자동화 편집기입니다. 이 저장소는 실행파일과 공개 배포 안내를 제공합니다.

- [최신 실행파일 다운로드](https://github.com/DrFREEST/Expert-Looper-Releases/releases/latest/download/ExpLooper.exe)
- [버전별 변경 내용과 다운로드](https://github.com/DrFREEST/Expert-Looper-Releases/releases)
- [전체 변경 내역](CHANGELOG.md)
- [자동 업데이트 안내](자동%20업데이트%20안내.md)

Windows 10 2004 이상 / Windows 11, x64용 공개 시험 버전입니다.

## 설치와 업데이트

처음 사용하는 분은 실행파일을 쓰기 가능한 폴더에 저장하고 실행해 주세요. 기존 사용자는 **도움말 → 업데이트 확인**으로 업데이트할 수 있습니다. 직접 교체할 때는 프로그램을 종료한 뒤 기존 폴더의 **ExpLooper.exe만 교체**하고 **Data 폴더는 그대로 유지**해 주세요. 새 폴더에서 실행하면 별도 작업 공간으로 시작합니다.

업데이트 자동 확인은 시작 시와 실행 중 1시간 간격으로 동작합니다. 설치는 사용자 확인 후 진행합니다. GitHub 로그인이나 API 키 입력은 필요하지 않습니다.

## 배포본 안내

버그 제보 채널 주소가 평문으로 포함됐던 **0.11.0 배포본은 공개 다운로드에서 제거했습니다.** 해당 버전을 사용 중이면 **0.11.1 이상**으로 업데이트해 주세요.

0.11.1은 버그 제보 채널 주소에 암호화·난독화를 적용했습니다. 이는 단순 문자열 검색으로 주소가 드러나는 것을 줄이는 조치이며, 실행파일 분석에 대한 완전한 비밀 보호를 보장하지 않습니다.

## 버그 제보

**도움말 → 버그 제보**에서 사용자명(디스코드 닉네임)과 버그 내용을 작성할 수 있습니다. 화면 캡처나 이미지 파일 1장을 선택적으로 첨부할 수 있으며, 제출 내용에는 사용 프로그램 버전이 포함됩니다.

실행파일의 오픈소스 라이선스는 프로그램 도움말에서 확인할 수 있습니다.
