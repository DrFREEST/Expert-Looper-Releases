## 반복 작업이 루틴이 되는 과정

![동작을 연결하고 확인한 뒤 반복하는 네 컷 소개](이미지/루틴%20소개%20웹툰.png)

*활용 흐름을 설명하는 소개 그림입니다. 실제 프로그램 화면은 아래 사용 안내에서 확인하세요.*

## 어떤 일을 할 수 있나요?

Expert Looper는 자주 반복하는 화면 작업을 **보고, 판단하고, 실행하는 루틴**으로 만드는 도구입니다. 업무 도구와 반복 테스트 등 여러 Windows 프로그램에 활용할 수 있습니다.

| 하고 싶은 일 | 이렇게 구성해 보세요 |
|---|---|
| 같은 작업 반복하기 | 클릭·키보드 입력·대기를 연결하고 횟수 반복 또는 정지할 때까지 반복 |
| 화면에 맞춰 다른 작업하기 | 이미지나 글자를 찾고, 조건별로 실행할 동작 연결 |
| 여러 항목을 차례로 처리하기 | 공통 변수·목록·데이터 테이블과 반복 동작 조합 |
| 만들어 둔 작업 다시 사용하기 | 서브 루틴·공통 모듈과 이미지·OCR 리소스로 정리 |
| 처리 결과 남기기 | 화면을 캡처하고 Discord 웹훅으로 결과 전송 |
| 복잡한 흐름 살펴보기 | 블록·노드 보기, 중첩 구조, 확대·축소와 전체 지도로 탐색 |

대상 프로그램에 따라 화면 인식과 입력 호환성이 다를 수 있습니다. 처음에는 짧은 루틴으로 확인한 뒤 작업을 늘려 주세요.

## 처음 시작하기

### 1. 다운로드하고 폴더 준비하기

위의 **실행파일 다운로드**를 눌러 `ExpLooper.exe`를 저장하세요. 문서 폴더 안에 `ExpertLooper` 폴더를 만들어 보관하면 찾기 쉽습니다. 다운로드에 GitHub 로그인이나 API 키는 필요하지 않습니다.

| 항목 | 안내 |
|---|---|
| 운영체제 | Windows 10 2004 이상 또는 Windows 11 |
| 시스템 | x64, 쓰기 가능한 저장 폴더 |
| 실행파일 | `ExpLooper.exe` — 별도 .NET 설치 없이 실행 |
| 인터넷 | 업데이트 확인·다운로드와 Discord 전송 등에 필요 |

### 2. 실행하고 작업 준비하기

저장한 실행파일을 실행하세요. Windows에서 권한 확인을 요청하면 파일의 출처를 확인한 뒤 진행하세요. 현재는 정식 1.0 출시 전의 **공개 시험 버전**입니다. 중요한 프로젝트는 별도 사본을 보관해 주세요.

### 3. 작은 루틴부터 만들어 보기

1. 새 프로젝트를 만들고 작업할 대상 창을 연결합니다.
2. 클릭이나 키보드 입력처럼 필요한 동작을 추가합니다.
3. 화면 변화가 필요한 지점에는 대기나 이미지·텍스트 확인을 넣습니다.
4. 먼저 한 번 실행해 순서와 인식 결과를 확인합니다.
5. 원하는 대로 동작하면 반복 블록으로 감싸고 프로젝트를 저장합니다.

**예시:** `화면의 “완료” 글자 확인 → 화면 캡처 → 다음 버튼 클릭`처럼 눈으로 확인할 수 있는 짧은 흐름부터 시작해 보세요. 반복 중에도 언제든 멈출 수 있도록 정지 조작을 먼저 확인해 두면 편리합니다.

## 실제 화면으로 따라 해 보기

아래 화면은 **별도 연습 프로젝트를 실제 Expert Looper 편집기에 열어 캡처한 이미지**입니다. 개인 프로젝트나 연결 정보는 포함하지 않았습니다. 이미지를 클릭하면 크게 볼 수 있습니다.

### ① 작업 공간 살펴보기

![실제 편집기의 첫 반복 루틴](이미지/첫%20반복%20루틴.png)

왼쪽에서 프로젝트와 루틴을 선택하고, 가운데 캔버스에서 실행 순서를 봅니다. 오른쪽은 선택한 동작의 요약입니다. 위 예제는 **루틴 시작 → 1초 기다리기를 3번 반복 → 루틴 종료** 순서입니다. 큰 반복 블록 안에 실제로 반복할 동작이 들어갑니다.

### ② 필요한 동작 붙이기

![동작 추가 창의 기본 블록 목록](이미지/동작%20추가%20창.png)

캔버스 위 **동작 추가**를 누르고 원하는 블록을 고르세요. 처음에는 **잠깐 기다리기**로 연습하면 다른 프로그램을 조작하지 않고 흐름을 익힐 수 있습니다. 검색창으로 찾거나 **모든 블록 보기**를 켜서 OCR·프로그램·카운터 등의 항목도 확인할 수 있습니다.

### ③ 반복 횟수 정하기

![여러 번 반복하기의 횟수 설정](이미지/반복%20설정%20창.png)

**여러 번 반복하기** 블록을 추가하고 반복 방식과 횟수를 정합니다. 화면처럼 **횟수만큼 / 직접 입력 / 3**을 지정한 뒤 **적용**하세요. 반복 블록 안의 **+**로 기다리기 동작을 넣으면 위 예제와 같은 흐름이 됩니다. 정지할 때까지 반복하는 방식도 선택할 수 있지만, 처음에는 작은 횟수로 확인해 보세요.

### ④ 저장하고 짧게 확인하기

**Ctrl+S**로 프로젝트를 저장하세요. 시작 전 흐름을 확인하고, 준비가 끝나면 **재생**을 누릅니다. 기본 재생 키는 **F6**, 정지는 **F8**이며 사용자 설정에 따라 다를 수 있습니다. 실제 지정된 키는 **설정 → 단축키 설정**에서 확인하세요.

## 업데이트하기

### 프로그램 안에서 업데이트

**도움말 → 업데이트 확인**을 선택하세요. 새 버전이 있으면 안내를 확인하고 설치할 수 있습니다. 자동 확인을 켜 두면 시작할 때와 실행 중 **1시간 간격**으로 새 버전을 확인합니다. 확인만으로 자동 설치되지는 않습니다.

업데이트 전에는 편집 내용을 저장하세요. 설치 과정에서는 실행 중인 작업을 정지하는 안내가 표시되며, 업데이트 후에는 변경 내용도 확인할 수 있습니다.

### 실행파일을 직접 교체한다면

1. 프로젝트를 저장하고 Expert Looper를 종료합니다.
2. 새 `ExpLooper.exe`를 다운로드합니다.
3. **기존 폴더의 실행파일만 교체**합니다.
4. 같은 폴더에서 다시 실행합니다.

> **`Data` 폴더는 그대로 두세요.** 새 폴더에서 실행하면 별도 작업 공간으로 시작합니다. 기존 작업이 보이지 않으면 먼저 실행한 폴더가 맞는지 확인하세요.

자세한 설치 흐름은 [자동 업데이트 안내](자동%20업데이트%20안내.md)에서 확인할 수 있습니다.

## 문제가 생겼나요?

프로그램의 **도움말 → 버그 제보**를 이용해 주세요. 재현 과정을 함께 알려주시면 문제를 파악하는 데 도움이 됩니다.

| 입력 항목 | 작성 방법 |
|---|---|
| 사용자명(디스코드 닉네임) · 필수 | 답변을 확인할 때 사용할 닉네임을 적어 주세요. 서버 가입 인증 과정은 없습니다. |
| 버그 내용 · 필수 | 무엇을 하다가, 어떤 결과가 나왔고, 무엇을 기대했는지 적어 주세요. |
| 이미지 · 선택 | 화면에서 캡처하거나 파일을 첨부하세요. 1장, 최대 8MB이며 미리보기가 가능합니다. |
| 사용 프로그램 버전 | 제출 내용에 자동으로 포함됩니다. |

제출 전 이미지에 개인정보나 웹훅 URL 같은 민감한 정보가 없는지 확인해 주세요. 프로젝트와 로그는 자동으로 첨부하지 않습니다.

## 자주 묻는 질문

<details>
<summary><strong>GitHub의 Assets에서는 어떤 파일을 받나요?</strong></summary>

**ExpLooper.exe**를 받으세요. `update.json`은 자동 업데이트용 정보 파일입니다. `Source code` 압축파일은 실행파일이 아닙니다. 이 페이지 상단 링크를 누르면 실행파일을 바로 받을 수 있습니다.

</details>

<details>
<summary><strong>업데이트 뒤 기존 프로젝트가 안 보여요.</strong></summary>

이전과 같은 폴더에서 실행했는지, 기존 `Data` 폴더가 남아 있는지 확인하세요. 작업 폴더를 옮길 때는 실행파일만 따로 이동하지 말고 기존 데이터도 함께 보관하세요.

</details>

<details>
<summary><strong>이미지나 글자가 잘 인식되지 않아요.</strong></summary>

찾을 대상이 실제로 보이는지 확인하고, 가능하면 필요한 부분으로 검색 영역을 좁혀 보세요. 창 크기·배율·배경 효과·글자 모양에 따라 결과가 달라질 수 있습니다. 반복해서 실패한다면 화면 예시와 재현 과정을 버그 제보에 첨부해 주세요.

</details>

<details>
<summary><strong>AI 커넥터를 꼭 켜야 하나요?</strong></summary>

아니요. 직접 루틴을 만들고 편집할 때는 필요하지 않습니다. AI 커넥터는 지원하는 로컬 에이전트가 프로젝트·모듈·리소스 편집을 돕는 선택 기능입니다. 에이전트 측 연결 설정이 필요하며, 모든 채팅 앱에서 스위치만으로 연결되는 것은 아닙니다. 루틴 재생과 실제 입력은 커넥터 지원 범위에 포함되지 않습니다.

</details>

<details>
<summary><strong>0.11.0 다운로드가 보이지 않아요.</strong></summary>

버그 제보 채널 주소가 평문으로 포함됐던 0.11.0은 공개 배포에서 제거했습니다. **0.11.1 이상**을 사용해 주세요. 0.11.1에는 주소 암호화·난독화를 적용했으며, 실행파일 분석에 대한 완전한 비밀 보호를 보장하는 방식은 아닙니다.

</details>
